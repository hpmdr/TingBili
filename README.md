> 某站上有海量的有声小说、多人有声剧、播客和公开课，可惜官方客户端是为「看视频」做的。
> TingBili 只做一件事：**让你像用听书 / 播客 App 一样，听某站的声音**——熄屏、后台、断点续播、定时关闭。

## 为什么做这个

平时喜欢在某站听有声书，但用官方客户端「听视频」有几个难受的地方：

- **太重了**：官方客户端功能越来越多，同一台手机实测，打开「听视频」页面时内存占用 PSS 约 1.3GB、RSS 约 1.5GB（光图形渲染部分就占约 600MB）。只是想睡前听个故事，手机却在发热耗电。
- **为看视频设计**：界面、推荐、交互全围绕画面来，熄屏听就是个附带功能。
- **长音频不好管**：几十上百小时的有声剧，听到哪了、下次接着听，都得自己记。

所以做了 TingBili：**不要视频画面，只要声音、字幕和进度**。同一台手机、同一时刻对比：TingBili 在后台播放时 PSS 仅约 140MB，前台使用也在 300MB 上下，不到官方客户端的零头（机型、版本不同会有差异，欢迎自己验证：`adb shell dumpsys meminfo tv.danmaku.bili cn.debubu.tingbili`）。

轻，是因为我们压根不解码视频、不渲染弹幕、不预加载一堆和「听」无关的东西。

## 它能帮你做什么

- 📻 **海量有声内容随便听**：首页有听书推荐，搜一下就有——有声小说、多人有声剧、播客、公开课，某站上有声音的都能听。
- 🌙 **熄屏、后台稳定播**：锁屏、蓝牙耳机、线控都能用；来电话、拔耳机自动暂停，忙完回来接着听。
- 🔖 **断点续播**：几十小时的长视频，听到一半退出，下次打开自动从上次的位置继续，不用自己记。
- 😴 **睡前定时关**：15 / 30 / 60 / 90 分钟或自定义时长，到点自动停，安心睡。
- ⏩ **倍速 + 快进快退**：0.5~3 倍速，5~60 秒自定义步进，跳过片头、回听细节都方便。
- 💬 **字幕当电子书看**：字幕逐行滚动、高亮跟随，点任意一句就跳到那一句；没听清的地方看一眼就行。
- 📚 **自建歌单**：喜欢的书、合集一键成辑，增删改、排序、拖拽都行；多 P 系列自动整理成一集一集。
- 🔗 **某站账号打通（扫码登录）**：收藏夹、稍后再看、观看历史同步过来，在哪收藏的都不丢。
- 📦 **省流量、省空间**：只拉音频流，不下视频画面；离线缓存上限自己定，WiFi 下好书再慢慢听。
- 🎨 **看着顺眼**：支持跟随系统取色，也有默认粉色和自定义颜色，手机平板自适应布局。

## 下载安装

- 去 [Releases 页](https://github.com/hpmdr/TingBili/releases/latest)下载最新版的 `TingBili_*_android.apk`（如 `TingBili_0.1.0_android.apk`，附 `.sha256` 校验），手机浏览器打开直接安装（正式签名，后续版本可覆盖更新）。
- 需要 Android 12 及以上。
- 注：debug 包和 release 包签名不同，之前装过 debug 版的需先卸载（本地听书进度会丢，某站账号里的收藏不受影响）。
- 想自己编译、改代码？看 [开发指南](docs/DEVELOPMENT.md)。

## 常见问题

- **需要某站账号吗？** 不用也能搜、能听。扫码登录后可以同步你的收藏夹、稍后再看和历史。
- **要一直亮着屏吗？** 不用。熄屏、切后台、锁屏都能播，通知栏和锁屏可以直接暂停 / 切集。
- **费流量吗？** 只拉音频流，比看视频省得多；也支持 WiFi 下缓存好再听。
- **和官方客户端冲突吗？** 不冲突，可以同时装。两边历史互不影响，登录的是同一个某站账号而已。
