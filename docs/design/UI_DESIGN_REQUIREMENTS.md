# TingBili 全 App UI 设计需求（喂给设计 AI 的完整输入）

> 适用对象：UI 设计 AI。目标：一次性产出 **全 App 完整 UI 设计**（不再分阶段给需求）。
> 实现会分阶段落地，但设计必须一次成体系。本文每个功能点均来自代码实现，
> “禁止脑补清单”之外的内容一律不许自行发明。

---

## 0. 应用一句话

TingBili：B 站（bilibili）专用**音频播放器**，主场景是**听书 / 有声小说 / 广播剧**
（把 B 站视频当纯音频听）。单 Activity、全 Jetpack Compose、Material 3。
**游客模式，无登录、无账号、无社交。** 仅供学习交流。

## 1. 全局约束（所有页面必须同时满足）

### 1.1 主题：三模式 × 深浅色

主题由用户在设置页三选一，设计稿必须同时给出 **浅色 + 深色** 两套，且不能锁死品牌粉：

| 模式 | 主色来源 | 设计含义 |
|---|---|---|
| 默认 | 品牌粉 `#FF6699` 派生的整套色板 | 主色、主色容器、次色、指示块全部由此粉派生 |
| 跟随系统 | Android 12+ 壁纸动态取色（Dynamic Color） | **主色可能是任意颜色**，禁止出现"粉色是唯一主色"的假设；所有强调色必须用 M3 色彩角色（primary / secondaryContainer 等），不许写死粉色 hex |
| 自定义 | 用户用 HSV 色板任意选色，色板按规则派生（深色提亮 12%、容器压暗等） | 同上，任意种子色下文字对比度必须达标（内容色按亮度自动黑/白） |

- 全 App edge-to-edge 沉浸式：内容顶到状态栏下，顶栏自行避让；状态栏/导航栏透明。
- 字阶严格用 M3 Type Scale，不许自创字号。

### 1.2 横屏竖屏

- 应用允许旋转（未锁方向）。手机竖屏 1220×2712 为主，横屏约 2712×1220 必须可用。
- 导航模式按 M3 Adaptive：竖屏（Compact）底部 NavigationBar；横屏/宽屏（Medium/Expanded）
  左侧 NavigationRail。旋转时**导航选中态、播放状态、播放进度全部连续**（不重播、不丢位置）。
- 全屏播放页横屏要重排（左右双列：封面区 + 播控区），不许竖屏硬拉伸。

### 1.3 反脑补清单（⛔ 绝对禁止自行添加）

- 无登录/注册/个人中心；无评论、无弹幕展示（只读统计数字）、无点赞投币按钮、无分享页；
- 无下载/离线缓存管理页（只有播放缓存，后台自动，用户只调上限）；
- 推荐页**无 Banner、无榜单、无分类 Tab**，就是一版自适应网格信息流；
- 睡眠定时**后端已就绪但尚无入口**（见 2.8），请为它设计播放页入口，不要以为它已存在；
- 所有"加载中 / 加载失败+重试 / 空内容"三态每页都要设计（文案见各页）；
- 操作反馈用 Toast（收藏成功/失败、移除成功等），保留轻反馈、不许改成弹窗确认（删除类除外）。

### 1.4 无障碍与文案

- 全部图标按钮补 `contentDescription`（当前代码多处缺失，新设计逐项给出）。
- 中文数字单位沿用：`1.2万 / 3.4亿`；时长 `m:ss` / `h:mm:ss`；收藏总时长 `X小时Y分 / X分钟 / 不足1分钟`。
- 现有中文文案（见各页引号）除非 special 说明，**一字不改**，设计只改视觉表达。

## 2. 页面功能清单（共 8 页：4 Tab + 4 独立页）

### 2.1 Tab · 推荐（发现流，默认首页）

- 头部（特型，不走统一顶栏，是否收编由框架设计定）：左侧品牌大字 `TingBili` +
  右侧圆角假搜索框（放大镜图标 + 占位文案 `搜索 B站视频 / 关键词`），点击进搜索页。
- 内容：自适应网格（最小列宽 156dp），卡片 = 16:9 封面（圆角 10dp）+
  右下角时长黑底小标签 + 两行加粗标题 + 一行 `UP: 作者名 · NP`（多 P 才有后半）。
- 数据源是**固定策展关键词**的信息流（非个性化推荐，不要设计"猜你喜欢"理由/算法标签）。
- 状态：首次加载居中转圈；有内容时刷新顶部细线性条；上拉追加底部小圈；
  失败红字 + `重试` 按钮；空 `暂无推荐内容`。点卡片进视频详情页。

### 2.2 Tab · 收藏

- 统一顶栏：标题 `收藏`，有内容时副标题 `共 N 个收藏夹`。
- 列表为卡片（surfaceContainerHigh，1dp 海拔）：72dp 圆角封面（无封面用唱片图标占位）+
  收藏名（2 行）+ `N集 · X小时Y分` + 主色 `上次听到 P7 · 11:57 / 30:01`（有进度才显示）+
  `合集 · 2026-09-17` / `自建歌单 · 2026-09-17` + 右箭头。点卡片进收藏详情。
- 空态：`暂无收藏，去视频详情收藏一个吧`。收藏唯一来源是详情页"一键收藏"（整 BV 存入）。

### 2.3 Tab · 历史

- 统一顶栏：标题 `历史记录` + 副标题 `共 N 条播放记录` + 右侧文字按钮 `清空`
  （当前直接清空，请设计**二次确认**）。
- 列表为卡片行：108×64 封面 + 主标题（**书名**，即 BV 总标题）+ 章节行
  `P7 · 章节名 · UP主`（章节名会自动剥掉与书名重复的前缀，纯数字章节只留 `P7`）+
  右侧日期 `MM-dd` + 主色 `上次听到 …` + 4dp 细进度条 + 删除图标键。
- 点卡片 = **从上次位置续播**。空态：`暂无播放记录`。

### 2.4 Tab · 设置（内容最复杂，逐项列出）

1. **主题色**：三选项 `默认 / 跟随系统 / 自定义`（各带色板预览圆点）+
   当前模式说明行（默认：`默认听视频粉 #FF6699`；跟随系统：显示当前系统主色 hex）。
   点"自定义"弹 HSV 对话框：色相 0~360 / 饱和度 / 亮度三滑杆 + hex 预览 + `应用 / 取消`。
2. **前进/后退步长**：`前进 / 后退步长: N 秒` + 滑杆（5~60）+ 快捷按钮 `5s 15s 30s 60s`。
3. **B 站图片格式**：`AVIF 省流量 / WebP 均衡 / JPEG 兜底` 三选一 +
   说明 `默认 AVIF；若遇到图片无法显示，可切换 WebP 或 JPEG。`
4. **定时预设（分钟）**：`15分 30分 60分 90分` 四按钮（这是睡眠定时的时长预设）。
5. **音频缓存**：`已缓存约 X / YMB`（X 精确到 0.1MB，未满 1MB 显示 KB）+
   上限五档 `100MB 200MB 500MB 1GB 2GB` + 说明 `调整上限后重启应用生效；
   调小后超量部分会在使用中按最近最少使用逐出。` + `刷新 / 清空缓存` 按钮。

### 2.5 独立页 · 搜索（无底栏）

- 顶行：返回键 + 输入框（进页自动聚焦弹键盘；有字时清空键；回车/=搜索键触发；
  占位 `搜索 B站视频 / 关键词`）。
- 未输入：`输入关键词搜索 B站视频`；无结果：`没有找到相关视频`。
- 结果行：116×72 封面 + 左下时长 + 两行标题 + `UP: … · NP`。失败红字 + `重试`。
- 点行进视频详情页。

### 2.6 独立页 · 视频详情（无底栏）

- 统一顶栏：标题 `视频详情` + 返回键。
- 16:9 大封面（圆角 12dp）→ 标题（3 行）→ UP 行（36dp 圆头像 + `UP: 名` +
  `分区 · yyyy-MM-dd`）→ 统计行（`1.2万 播放 · 3000 弹幕 · 点赞 · 投币 · 收藏`，
  为 0 的项省略）→ 双按钮：`播放 / 播放全部 (NP)` + `收藏 / 已收藏`（书签图标切换）。
- 有简介才显示 `简介` 段；多 P 显示 `分P列表 (共NP)`：行 = 主色 `P1` + 标题 +
  时长，点行即播该 P 并进播放页。
- 三态：加载转圈 / `加载失败：…` + `重试`；收藏操作结果用 Toast 反馈。

### 2.7 独立页 · 收藏详情（无底栏）

- 统一顶栏：标题 = 收藏名 + 返回 + 右侧 `更多` 菜单（`重命名 / 删除收藏`）。
- 240dp 横幅：模糊大封面底 + 渐变罩 + 居中 96dp 封面 + 名 + `N集 · yyyy-MM-dd`
 （无封面用主色渐变 + 唱片占位）。
- 通栏 `全部播放` 大钮（圆角 20dp，无内容时禁用）→ `集列表 / N集` 表头 →
  行：主色序号 `01` + 标题（2 行）+ 主色 `上次听到 …`（有进度才有）+ 删除键
  （弹二次确认：标题 `移除这一集？` + 内容标题 + `移除 / 取消`）。
- 重命名弹窗：标题 `重命名收藏` + 输入框（占位 `收藏名称`）+ `确定 / 取消`。
- 空态：唱片图标 + `暂无内容` + `去推荐添加一个有声书吧`。

### 2.8 独立页 · 全屏播放（无底栏，最重要）

- 顶栏：返回 + 居中合集名（长标题 22sp→14sp 自适应缩小，最多两行）+
  右上倍速键（`1.0x` 字样，多档循环切换，加载中禁用）。
- 方形封面（宽 76%、最大 320dp、圆角 24dp、大阴影）→ 章节大标题（2 行居中）→ UP 名。
- 错误红字行；加载中 `转圈 + 正在加载...`。
- **字幕区**（B 站字幕，不是歌词）：居中列表，当前行主色放大加粗，**点行跳播**，
  自动跟随滚动；无字幕时该区域留白（不要画空列表骨架）。
- 进度条：三层圆角条（底 / 半透明缓冲 / 主色播放）+ 空心圆钮（拖拽放大），
  上方左 `已播 / 总时长`、右 `-剩余`；拖拽松手才 seek。
- 控制行五键：上一首 / 后退 N 秒（数字压在旋转箭头图标上）/ 64dp 主色播停大钮
  （加载中变 36dp 转圈）/ 前进 N 秒 / 下一首；加载中全部禁用。
- 行为：冷启动自动恢复上次队列 + 进度；B 站链接约 2 小时过期，后台静默刷新、
  用户只看到短暂加载（设计**不要**为"刷新链接"做任何显性 UI）。
- **待设计**：睡眠定时入口（后端已就绪：设时长→到点暂停，可取消，有剩余时间状态；
  时长预设 15/30/60/90 在设置页）。请在播放页安排入口 + 倒计时显示，
  并与设置页预设联动。
- 系统侧：通知栏/锁屏/耳机线控走标准媒体通知（系统 UI，不用设计，但存在）。

## 3. 交付要求（给设计 AI 的输出约束）

1. 全 8 页 + 框架（顶栏体系/导航/悬浮 mini 条/容器）一次出完，竖屏横屏各一套，
   浅色深色各一套；跟随系统与自定义主题下**不许出现写死粉色的部件**。
2. 输出 M3 token 表（颜色/字阶/圆角/海拔）+ 无障碍标签清单。
3. 动效：Tab 切换、mini 条出现/消失/展开、旋转过渡、全屏播放页展开方式。
4. 对比表：相对现状改了什么、为什么；**自查表**：逐条声明 1.3 禁止清单零违反、
   2.x 每页元素无遗漏（特别是 2.4 设置页 5 组、2.8 播控 5 键 + 定时入口）。
5. 实现约束：优先 M3 官方 + 自适应组件
  （TopAppBar、NavigationBar、NavigationRail、NavigationSuiteScaffold、
   Slider、FilterChip、Dialog、DropdownMenu 等）组合；自绘部分（进度环、封面阴影、
   自定义进度条）单独标注实现要点。
