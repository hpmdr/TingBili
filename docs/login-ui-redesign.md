# 听视频（TingBili）登录页 UI 重设计说明

> 用途：交付 UI 设计（可整段复制）。只重做界面，**不改功能和逻辑**。

---

## 一、我们是什么 App

- **产品名**：听视频（TingBili），包名 `cn.debubu.tingbili`。
- **定位**：B 站（哔哩哔哩）专用的**音频播放器**，把 B 站当听书 / 播客 App 用。不渲染视频、不解码画面、不加载弹幕，只保留声音、字幕和进度。
- **核心能力**：熄屏播放、后台播放、断点续播、定时关闭、字幕跟读与逐句跳转、倍速、章节、本地收藏与历史。
- **平台**：Android 12 及以上，全 Jetpack Compose + Material 3，单 Activity，全面屏 edge-to-edge。
- **登录的意义**：不登录也能听（本地收藏/历史可用）；登录后解锁高音质、字幕、B 站收藏 / 历史 / 稍后听同步。
- **性质**：第三方非官方客户端，仅供学习交流，AGPLv3 开源。

### 主要页面

- 底部 4 个 Tab：**首页 / 听单 / 历史 / 我的**（手机为底部导航 + 中央播放按钮，平板为 NavigationSuite 侧栏）。
- 全屏二级页：播放页、搜索、视频详情、UP 主页、收藏详情、**登录页**、各类设置页。
- 登录页是独立全屏页：无底部导航，无迷你播放器。

---

## 二、目前的视觉风格

整体是**克制的 B 站风 Material 3**：粉色品牌色 + 大量留白 + 圆角卡片，信息密度中等，不使用花哨装饰。

### 主题与颜色

- 默认品牌主色：**B 站粉 `#FF6699`**。
- 「我的」页另有 B 站粉 `#FB7299` / `#FF69B4`、B 站蓝 `#00A1D6` 作为局部强调色。
- 支持三种主题模式：
  - 系统动态取色（Android 12+ Material You）；
  - 默认品牌粉；
  - 用户自定义主题色（任意色值生成整套配色）。
- 浅色 / 深色双主题；深色额外支持 **AMOLED 纯黑**（背景 `#000000`，卡片按层级 `#0A0A0A` ~ `#242424`，保证层次）。
- 语义色使用 M3 规范：主色、容器色、`errorContainer` 错误条、`onSurfaceVariant` 次要文字。

### 形状与尺寸

- 卡片圆角 16–20dp；输入框、分段控件 14dp；主按钮高 52dp、圆角 14dp；二维码区域圆角 20dp。
- 页面左右边距 16dp；内容最大宽度 **520dp** 居中（平板/横屏不拉通栏）；块间距 16dp；卡片内边距 20dp。
- 触控目标不小于 48dp。

### 字体与图标

- 使用 Material 3 默认字体体系（系统字体），无自定义字体。
- 标题用 `titleMedium` / `bodyLarge` + SemiBold；说明文字用 `bodySmall`，`onSurfaceVariant` 弱化。
- 图标统一 Material Icons Filled（耳机、扫码、短信、钥匙、Cookie、锁、刷新、错误、眼睛等）。

### 页面风格参考

- **我的页**：沉浸式 B 站粉渐变头部 + 悬浮四宫格数据卡 + 分组圆角设置列表，B 站氛围最浓。
- **播放页**：以深色为主，字幕区跟读高亮，底部一排圆形控制按钮 + 播放进度。
- **首页 / 听单 / 历史**：浅色卡片流，封面图圆角，信息层级清晰。
- **登录页**：顶部返回 + 标题，价值说明行，四段式登录方式切换，单张表单卡片，底部隐私提示。

### 文案风格

- 简体中文、短句、直接。
- 会解释「为什么」和「失败怎么办」，例如风控、Cookie 获取步骤。
- 不堆技术术语，不把接口报错原文抛给用户；语气友好、可信。

## 三、登录页当前的功能现状

### 页面结构

- 全屏二级页，顶部标题「登录哔哩哔哩」+ 返回按钮。
- 页面内有 4 个登录方式入口：**扫码 / 短信 / 密码 / Cookie**，默认选中扫码。
- 切换方式会切换表单；**已输入内容不跨方式保留**。
- 登录成功（会话变为非空）或用户返回，都会离开本页；成功后自动回到来源页。

### 全局行为

- 进入页面自动获取二维码并开始轮询；离开页面停止轮询。
- 扫码轮询间隔 2 秒；二维码总有效期 180 秒。
- 切走扫码时停止轮询；切回时剩余时间 > 10 秒则沿用原码继续，否则重新取码。
- 请求进行中按钮禁用，防止连点。
- 所有错误都在表单内以提示条展示，不使用 Toast / Snackbar。
- 短信发送、密码登录前可能拉起**极验滑块验证弹窗**，滑块通过后才继续原操作。

### 1）扫码登录

- 状态：
  - 生成中：显示加载；
  - 待扫码：二维码 + 剩余秒数 + 刷新操作；
  - 网络波动：二维码保留，提示自动重试；
  - 扫码成功：进入登录收尾；
  - 过期 / 失败：提供「刷新二维码」。
- 倒计时归零或服务端判定过期，进入失败态。
- 轮询网络出错不会让二维码消失，会重试到过期。
- 目前**不区分「已扫码待手机确认」和「未扫码」**，两者界面表现一致。
- 手动刷新会换一张新码。
- 扫码确认后执行登录收尾；收尾失败（如换 Cookie 失败）展示失败提示与刷新入口。

### 2）短信登录

- 输入限制：
  - 区号：纯数字，最多 4 位，默认 86；
  - 手机号：纯数字，最多 15 位；
  - 验证码：纯数字，最多 6 位。
- 「获取验证码」按钮：
  - 发送中 / 登录中不可点；
  - 发送成功进入 **60 秒重发倒计时**，结束才能再次发送。
- 流程：校验手机号非空 → 获取极验票据 → 弹滑块 → 通过后发送短信 → 开始倒计时 → 光标自动跳到验证码框。
- 取消滑块：回到初始状态，不报错。
- 登录校验顺序：必须已获取过验证码 → 验证码非空 → 验证码未超过 5 分钟 → 提交登录。
- 失败提示：手机号为空、未获取验证码、验证码为空、验证码过期、发送失败、登录失败。
- 登录请求中按钮显示「登录中」并防止连点。

### 3）密码登录

- 输入：手机号 / 邮箱、密码；两者自动过滤空格。
- 密码支持显示 / 隐藏切换。
- 键盘「完成」等同点击登录。
- 流程：校验非空 → 获取极验票据 → 弹滑块 → 通过后 RSA 加密提交 → 成功返回。
- 取消滑块：回到可编辑状态，输入内容保留。
- 失败提示：账号或密码为空、获取验证信息失败、登录失败。

### 4）Cookie 导入（兜底）

- 展示 3 步电脑端获取 Cookie 的说明。
- 支持手动输入，也支持一键读取剪贴板填入。
- 内容为空时直接提示「请先粘贴 Cookie」，不发请求。
- 提交后进入「验证中」，成功即登录；失败展示原因（缺少 `SESSDATA`、Cookie 失效等）。
- 没有本地格式校验，格式解析与有效性判断都在数据层。

### 5）极验滑块弹窗

- 短信与密码登录共用。
- 弹窗内含滑块验证，标题「安全验证」。
- 验证通过后回调并继续原操作。
- 取消 / 关闭：中断原操作，恢复表单，不报错。
- 加载或解析失败时弹窗内显示错误，仍可取消。

### 6）登录成功后的行为

- 保存会话（用户信息 + 加密凭证）。
- 页面自动返回，无独立成功页；扫码模式会在表单内短暂显示「扫码成功，正在进入…」。
- 返回后，我的页、B 站收藏、历史、稍后听、播放页的登录态同步刷新。

### 当前没有的功能

- 注册、找回密码、第三方登录、记住密码。
- 游客绕过、登录后资料编辑。
- 已登录用户再次进入本页会被直接退回，不展示「已登录」状态。

## 四、重设计边界

**可以改**：布局、视觉层级、配色、圆角、图标、动效、文案排版、深色/浅色呈现、平板与横屏适配。

**必须保留**：

- 4 种登录方式及其切换；
- 所有状态（生成中 / 待扫码 / 网络波动 / 已过期 / 失败 / 成功 / 发送中 / 倒计时 / 验证中 / 提交中）；
- 输入限制、校验顺序与错误提示；
- 60 秒重发倒计时、180 秒二维码有效期、5 分钟验证码有效期、10 秒续码阈值；
- 极验滑块的中断与恢复逻辑；
- 登录成功自动返回，无独立成功页；
- 扫码轮询的启停与续码行为。

## 五、已知无障碍问题（暂不处理）

- **问题**：品牌粉 `#FF6699` 上的白字对比度约 **2.8:1**，低于 WCAG AA 的正常文字 4.5:1。
- **范围**：全局主题，所有主按钮与选中态都受影响；不是登录页独有。
- **决策**：保持 B 站品牌观感，**本期不处理**，记录为已知取舍。个人开源项目不属于强制合规场景。
- **若以后要改**：优先在主题层统一处理，避免只改登录页造成不一致。推荐方案：
  - 填充按钮/选中态改用更深一档的粉（如 `#D81B60` 左右，约 4.9:1），`#FF6699` 保留做图标与强调色；
  - 或保留 `#FF6699` 底色，把填充态文字改为深色（约 7.6:1）。
- **已达标项**：登录页触控目标 ≥ 48dp、图标有语义描述、输入框有常驻 label、错误不只靠颜色表达。
