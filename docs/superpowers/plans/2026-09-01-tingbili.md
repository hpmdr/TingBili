# TingBili Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从零搭建 `cn.debubu.tingbili` 专用音频 App（听书/听音乐），以后台音频为核心、歌单驱动，解决 B 站臃肿与多P/字幕/定时痛点。

**Architecture:** 方案B 特性模块化 Clean Architecture — `app` 壳 + `core:ui/media/data` + `feature:home/playlist/history/player/settings` + `data:bilibili`，单向数据流 `StateFlow`，Hilt 注入，Media3 MediaSessionService 为唯一可信播放源。

**Tech Stack:** Kotlin 2.1 + Compose BOM latest + Material3 + Navigation Compose 2.8 (type-safe) + Hilt 2.52 + Room 2.6 (KSP) + DataStore + Media3 1.4.1 + Retrofit 2.11 + OkHttp 4.12 + Kotlinx Serialization + Coil 2.7 + Paging3 + Coroutines, Gradle KTS + Version Catalog, AGP 8.7+, Java 17

## Global Constraints

- applicationId `cn.debubu.tingbili` verbatim
- minSdk 31, targetSdk 36, compileSdk 36, Java 17
- 无视频解码链路，ExoPlayer 仅音频，Service 不创建 Surface，目标常驻 <100MB，冷启动 <1s
- Material3 + dynamicColor + 深浅色 + 平板/横屏自适应 (NavigationBar / NavigationRail)
- 纯本地数据 (Room + DataStore)，无后端，游客可用，登录延后但预留 Auth 注入点
- 底部 4 Tab: 首页/歌单/历史/设置 + 底部居中圆形mini播放器 (圆环进度+旋转封面)
- Track 模型按 bvid+cid，BV 多P展开为 List<Track>，本地歌单可混排，去重按 bvid+cid
- 仅对接 4 公开 B API: search / view(多P) / playurl / subtitle (投稿优先>AI)，Wbi 隔离
- 版权/风控错误统一 Result<T> 映射
- 测试: TDD, 每个任务先写失败测试再实现

```kotlin
package cn.debubu.tingbili.core.ui.theme
import android.os.Build; import androidx.compose.foundation.isSystemInDarkTheme
import androidx.compose.material3.*
import androidx.compose.runtime.Composable; import androidx.compose.ui.platform.LocalContext
@Composable fun TingBiliTheme(darkTheme:Boolean = isSystemInDarkTheme(), dynamicColor:Boolean = true, content:@Composable ()->Unit){
  val scheme = when {
    dynamicColor && Build.VERSION.SDK_INT >= Build.VERSION_CODES.S -> {
      val ctx = LocalContext.current
      if(darkTheme) dynamicDarkColorScheme(ctx) else dynamicLightColorScheme(ctx)
    }
    darkTheme -> darkColorScheme()
    else -> lightColorScheme()
  }
  MaterialTheme(colorScheme=scheme, typography=Typography, content=content)
}
```
